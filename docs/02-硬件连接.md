# 02 硬件连接

本章把两只 P1 手套接到主机上，并确认主机认出了它们。基站的摆放、配对与标定在《03-基站使用与配对》。

## 1. 组成

一套 P1 由下面几部分组成：

| 部件 | 数量 | 说明 |
|---|---|---|
| 手套单元 | 2（左、右各一） | 每个单元含编码器手套、装在手背上的 Vive Tracker，以及单元内的 USB HUB；**一根 USB 线**接主机 |
| 基站 | 按场地 | SteamVR 基站，Tracker 靠它定位。摆放与配对见《03-基站使用与配对》 |
| 主机 | 1 | 满足《01-环境安装与系统要求》第 1 节，已装好全部软件 |

每个手套单元在主机上表现为两个 USB 设备，都挂在单元自己的 HUB 下：

| 设备 | USB ID | 在主机上的样子 |
|---|---|---|
| 手套 | `0483:5710` | 串口 `/dev/ttyACM*` |
| Tracker | `28de:2300` | USB 设备，由 libsurvive 读取 |

SDK 认得出哪个 Tracker 属于哪只手套：两者挂在同一个 HUB 下。

每只 Tracker 上有一个电源键和一个状态指示灯，使用前要先开机，见第 2.1 节。

## 2. 接线

1. 把两个手套单元的 USB 线分别插到主机的 USB 口上。**直接插主机**，不要经过无源 HUB 或 USB 延长线。
2. 左右手插哪个口都可以。SDK 按手套序列号区分左右手（左手序列号以 `BCRH1PL` 开头，右手以 `BCRH1PR` 开头），
   与插在哪个口、哪个先插上都无关。
3. 插好后等几秒，让系统枚举完设备。
4. 短按每只 Tracker 上的电源键开机，确认指示灯为绿色（见第 2.1 节）。

注意：

- 使用中（录制、实时广播、ROS 节点运行时）不要插拔手套。要换口时先关掉所有正在使用手套的程序。
- 串口编号 `/dev/ttyACM0`、`/dev/ttyACM1` 由插入顺序决定，重新插拔后可能对调。SDK 与 ROS 节点都按序列号找手套，
  **不要在自己的程序里写死串口编号**。
- 两只手分别接到主机不同的 USB 控制器上也能用，体检会给出提示（见第 3.2 节），双手时间对齐精度略低于接在同一控制器上。

### 2.1 Tracker 的电源键与指示灯

P1 使用的是 VIVE Tracker（3.0）。每只 Tracker 上有**一个电源键**（Tracker 上唯一的按键）和**一个状态指示灯**。
这个电源键与手套上的按键是两回事：手套按键用来控制录制，见《04-数据录制》第 8 节。

本套件的 Tracker 经手套单元的 USB 线把数据直接传给主机，**不使用无线接收器，也不需要在 SteamVR 里配对**。
Tracker 连着 USB 时可以边充电边使用。

电源键的操作：

| 操作 | 作用 |
|---|---|
| 短按一下 | 开机 |
| 按住约 5 秒 | 关机 |
| 按住约 2 秒 | 进入无线配对模式，指示灯蓝色闪烁。**本套件用不到**，误入时按下表处理 |

指示灯的颜色：

| 指示灯 | 含义 | 怎么做 |
|---|---|---|
| 绿色 | 正常模式：已开机、工作正常 | 可以继续使用 |
| 蓝色常亮 | 正在连接 | 等几秒，变绿后再继续；一直不变绿时，按住电源键约 5 秒关机，再短按开机 |
| 蓝色闪烁 | 无线配对模式（按住电源键约 2 秒会进入） | 本套件不需要无线配对：按住电源键约 5 秒关机，再短按开机 |
| 红色闪烁 | 电量低 | 保持 USB 线连接给它充电；已经自动关机时，充一会儿再短按开机 |
| 不亮 | 已关机 | 短按电源键开机 |

另有两种与充电有关的灯色：充电中为橙色；充满电后，关机时为白色、开机时为绿色。

按官方说明，Tracker 在电量耗尽、无线配对模式闲置超过 30 秒、或超过 5 分钟没有移动时会自动关机，
这时指示灯熄灭，短按电源键重新开机即可。

指示灯只反映 Tracker 自己的状态。Tracker 是否被主机认出，看第 3.3 节；是否看得到基站、位姿是否可用，
以《03-基站使用与配对》第 6 节 `tracker check --live` 的结果为准。

以上电源键与指示灯的说明依据 HTC 官方资料：
[指示灯](https://www.vive.com/us/support/tracker3/category_howto/checking-the-status-light.html)、
[开关机](https://www.vive.com/us/support/tracker3/category_howto/turning-on-or-off.html)、
[配对](https://www.vive.com/us/support/tracker3/category_howto/pairing-vive-tracker.html)。

## 3. 检查连接

### 3.1 串口

```bash
ls -l /dev/ttyACM*
```

示例输出：

```text
crw-rw---- 1 root dialout 166, 0 Sep 27 23:51 /dev/ttyACM0
crw-rw---- 1 root dialout 166, 1 Sep 27 23:51 /dev/ttyACM1
```

应看到两个串口，属组为 `dialout`。一个都没有时检查 USB 线；只有一个时说明另一只手套没接好。

### 3.2 体检

```bash
python3 -m revohuman doctor --probe
```

示例输出（两只手套接在同一台主机的两个不同 USB 控制器上）：

```text
⚠️  RevoHuman 手套体检 — 6 项检查：fail=0 warn=1
  ✅ 在位手套单元 — 2 个单元
    ✅ 1-1 — /dev/ttyACM0，无同 HUB 相机
    ✅ 3-1 — /dev/ttyACM1，无同 HUB 相机
  ✅ 手别认定 — 2/2 单元已认定手别
    ✅ 1-1 — —/left（按MCU 序列号）
    ✅ 3-1 — —/right（按MCU 序列号）
  ⚠️  USB 拓扑与电源管理 — 2 个单元完成拓扑解析
    ✅ 1-1 — 12Mbps @ 控制器 0000:05:00.3，autosuspend 已关
    ✅ 3-1 — 12Mbps @ 控制器 0000:05:00.4，autosuspend 已关
    ⚠️  双手拓扑分档 — cross-controller：……
  ✅ 固件版本与能力 — 2 个单元
    ✅ 1-1 — fw 0.20.3，ENCODER_ONLY，编码器 21，不带触觉型号（A 态）
    ✅ 3-1 — fw 0.20.3，ENCODER_ONLY，编码器 21，不带触觉型号（A 态）
  ✅ 流会话残留 — 2 个单元
    ✅ 1-1 — 无残留会话
    ✅ 3-1 — 无残留会话
  ⏭️  时间戳映射质量 — 需要活动数据流……
```

单元名 `1-1`、`3-1` 是 USB 口位置，随插的口不同而不同。上面唯一的 `warn` 是 `cross-controller` 提示，可以正常使用。

`--probe` 会短暂打开每只手套，读取固件信息并检查有没有上一个程序留下的数据流。**录制或其他程序正在使用手套时不要加 `--probe`**，
去掉它即可只做不打开设备的检查。

逐项含义：

| 检查项 | 通过时 | 不通过时 |
|---|---|---|
| 在位手套单元 | 列出 2 个单元及其串口 | 单元数不足或 `未发现手套单元`：手套没接好，看第 6 节 |
| 手别认定 | `2/2 单元已认定手别`，每个单元标出 `left` / `right` | 两只都认成同一只手或认不出：联系技术支持 |
| USB 拓扑与电源管理 | 每个单元 `autosuspend 已关` | `cross-controller` 只是提示（见第 2 节），可以正常使用 |
| 固件版本与能力 | 读出两只手套的固件版本与型号 | `读取失败`：手套正被别的程序使用；或下一项报有残留会话（见下一行） |
| 流会话残留 | `无残留会话` | 报有运行中的流会话：上一个使用手套的程序没有正常退出，手套还在发数。下次打开手套时 SDK 会自动停掉它，不需要处理 |
| 时间戳映射质量 | 需要数据流，体检里不做 | — |

判断标准：第一行显示 `fail=0`，**并且**「在位手套单元」列出了 2 个单元、「手别认定」为 `2/2`。
只看 `fail=0` 不够——一只手套都没接时体检也是 `fail=0`（「未发现手套单元」只算 `warn`）。

### 3.3 型号与左右手

```bash
python3 -m revohuman product identify
```

示例输出：

```text
型号 P1（依据：sn）  传感器：encoder, tracker
  left  手套 BCRH1PLXXXXXXXXXXX @ /dev/ttyACM0  tracker LHR-XXXXXXXX  触觉 none  相机 无
  right 手套 BCRH1PRXXXXXXXXXXX @ /dev/ttyACM1  tracker LHR-XXXXXXXX  触觉 none  相机 无
```

应看到 `型号 P1`、传感器 `encoder, tracker`，并且 `left` 与 `right` 两行都有手套序列号和 Tracker 序列号（`LHR-` 开头）。
某一行没有 Tracker 序列号时，该手套单元的 Tracker 没有被识别：先确认这只 Tracker 已开机、指示灯为绿色（第 2.1 节），
再重新插拔这个单元，仍不行时检查《01-环境安装与系统要求》第 6 节的
Tracker 设备规则是否已安装。

## 4. 佩戴

- Tracker 装在手背上，佩戴后手背朝外，**使用中不要用另一只手或物体挡住 Tracker**，否则它收不到基站的光、位姿会中断。
- 把 USB 线顺着手臂固定好，留出足够余量，避免抬手、转身时拉扯接口。
- 手套关节角的零位出厂前已标定好，戴好即可使用。只有更换过编码器磁铁、维修过手套，或零位明显偏移时，才需要按第 5 节重新标定。
- Tracker 的零位（双手摆在固定姿势时的位姿）与手套关节零位无关，在录制或 ROS 中按需记录，见《04-数据录制》与《06-ROS2》。

## 5. 手套关节零位标定

手套关节的零位姿态是**五指伸直、手掌平放**。零位标好时，手套摆在这个姿态下各关节读数都在 180° 左右。
出现下面几种情况时才需要重新标定：

- 更换过编码器磁铁，或维修过手套；
- 五指伸直平放时，个别关节的读数明显偏离 180°，而其他关节都在 180° 左右。
  读数可以在《05-仿真与可视化》固定基座视图的关节角表里看（`fw deg` 一列）。

标定会把手套**当前的姿势**记为新零位并写进手套，替换原来的零位（包括出厂零位），**无法撤销**，标错了只能摆好姿势重新标一次。
零位标错时手套照常输出数据，从数据里看不出来，所以标定前一定要摆好姿势。

一次标一只手，步骤如下：

1. 关掉所有正在使用手套的程序（`revohuman-live`、录制脚本、ROS 节点、可视化）。手套被占用时命令会直接拒绝。
2. 戴上或平放好要标的手套：**五指伸直、手掌平放**，保持不动。
3. 执行下面的命令（以左手为例，标右手时把 `left` 换成 `right`）：

```bash
python3 -m revohuman glove calibrate --hand left
```

4. 命令先打印要标的手套（左右手、USB 位置、串口、序列号），核对无误后输入 `yes` 回车，开始标定。标定完成前不要动手套。
5. 看到 `标定完成：…已保存到手套` 且退出码为 0，即为成功。

退出码：

| 退出码 | 含义 | 手套的零位 |
|---|---|---|
| 0 | 标定成功，新零位已保存到手套 | 已替换为新零位 |
| 1 | 标定失败或只有部分编码器成功（会列出成功与失败的编号） | 可能已部分替换：摆好姿势重新标一次 |
| 2 | 参数写错 | 未改动 |
| 3 | 拒绝执行：找不到这只手套、手套被其他程序占用，或没有确认 | 未改动 |

其他用法：

- 在脚本等非交互环境中执行时必须加 `--yes` 跳过确认，否则命令直接拒绝（退出码 3），不改动手套。
- 也可以用 `--port /dev/ttyACM0` 代替 `--hand`，按串口指定手套（必须是在位的手套串口）。串口编号插拔后可能对调，执行前核对命令打印的左右手与序列号。
- 全部参数：

```bash
python3 -m revohuman glove calibrate --help
```

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| `ls /dev/ttyACM*` 报 `No such file or directory` | 手套没接上：检查 USB 线两端是否插紧，换一个主机 USB 口再试 |
| 程序报串口 `Permission denied` | 当前用户不在 `dialout` 组，或加组后还没重新登录：见《01-环境安装与系统要求》第 5 节 |
| 体检只列出 1 个单元 | 另一只手套没接好，或接在了无源 HUB 上：直接插主机 |
| `product identify` 里某只手没有 Tracker 序列号 | 确认该 Tracker 已开机（第 2.1 节）；重新插拔该手套单元；检查 Tracker 设备规则（第 01 章第 6 节）是否已安装并重新插拔过 |
| 程序报错码 `1102`（手套被占用） | `revohuman-live`、录制脚本、ROS 节点或可视化正在使用手套，先关掉它；见《07-日志与错误码》 |
| 五指伸直平放时个别关节读数明显偏离 180° | 零位偏移，按第 5 节重新标定这只手套 |
| Tracker 指示灯不亮，或用着用着熄灭了 | Tracker 已关机（电量耗尽、配对模式闲置或长时间没有移动时会自动关机）：短按电源键开机，见第 2.1 节 |
| Tracker 指示灯蓝色闪烁 | 按住电源键时间过长，进入了无线配对模式。本套件不需要无线配对：按住约 5 秒关机，再短按开机 |
| Tracker 指示灯红色闪烁 | 电量低：保持 USB 线连接充电，可以边充边用 |
