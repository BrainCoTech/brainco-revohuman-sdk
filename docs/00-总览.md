# RevoHuman P1 用户手册

本手册面向 **RevoHuman P1**（编码器手套 + Vive Tracker）的使用者，从一台新装的 Ubuntu 22.04 开始，
讲到接好硬件、配好基站、录数据、看仿真、接 ROS 2，以及出问题时怎么查。

## P1 是什么

| 部件 | 说明 |
|---|---|
| 手套单元 ×2 | 左、右手各一：编码器手套（每手 21 个关节角，200 Hz）+ 手背上的 Vive Tracker（位姿，约 250 Hz），单元内一个 USB HUB，一根 USB 线接主机 |
| 基站 | SteamVR 基站 2.0，Tracker 靠它定位 |
| 主机 | Ubuntu 22.04，x86_64 或 aarch64 |

P1 没有全指触觉和腕部相机。

## 使用前要记住的几件事

- **同一时间只能有一个程序打开手套与 Tracker。** 录制脚本、`revohuman-live`、ROS 节点、可视化不要同时读手套；
  被占用时报错码 `1102`（手套）或 `1900`（Tracker），见《07-日志与错误码》。
- **左右手按手套序列号识别**，与插哪个 USB 口、`/dev/ttyACM` 编号无关，不要在程序里写死串口。
- **基站标定好之后不要移动基站。** 动过就要重新标定；SDK 发现基站被挪动时会停止采集并提示重新标定，
  但平移或水平转动基站检测不到（单台、多台基站都是如此），见《03-基站使用与配对》第 7、8 节。
- 命令行工具统一用 `python3 -m revohuman …` 调用；`revohuman-lighthouses`、`revohuman-live` 是另外两个命令。

## 文档里的约定

- 命令块都在普通用户的终端里执行，需要管理员权限的命令写明了 `sudo`。
- 示例输出里的设备序列号已替换成 `X`：手套 `BCRH1PLXXXXXXXXXXX`、Tracker `LHR-XXXXXXXX`、基站 `FAXXXXXXXXXX`，
  请以自己设备上的实际输出为准。时间戳、数值每次运行都不同。
- 手册中的命令已在发布前的候选构建上，用干净的 Ubuntu 22.04 与接好两只 P1 手套、Tracker 和基站的真机做过验证。
