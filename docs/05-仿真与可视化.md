# 05 仿真与可视化

发布包的 `simulation/` 目录里有一个三维可视化程序，在一个窗口里实时显示一副 P1 手套：

| 视图 | 内容 |
|---|---|
| 左：笛卡尔视图（CARTESIAN） | 双手按 Tracker 给出的位置与姿态摆在同一个世界坐标系里，手指随关节角一起动 |
| 右：固定基座视图（FIXED BASE） | 两只手固定摆放，只看手指关节；旁边列出关节角表 |

数据来自 SDK 的本机广播：命令 `revohuman-live` 打开手套与 Tracker，把关节角与位姿广播给本机的订阅方；
可视化只订阅这路广播，**不直接访问手套和 Tracker**。因此两者分开启动、分开退出，
也可以同时开多个可视化窗口看同一路广播。

> **URDF is coming soon.** 可视化要用手部模型（URDF 与网格）把关节角画成手，这份模型即将提供，
> 暂不在本发布包内。**仿真与可视化需要等 URDF 就位后才能使用**：在此之前运行 `./run_viewer.sh`
> （包括 `--demo`）会提示 `手部模型（URDF）尚未随本发布包提供` 并退出（退出码 2）。
> URDF 就位后放在源码包根目录的 `description/` 下（`urdf/` 与 `meshes/` 两个子目录），
> 或用 `--urdf-dir <目录>` 指定所在位置。数据采集、录制与 ROS 2 都不依赖手部模型。

## 1. 开始之前

- 已按《01-环境安装与系统要求》执行完全部步骤，包括第 9 节「安装三维可视化环境」。
- 手部模型（URDF）已就位（见本章开头）。
- 使用真手套时，还需要按《02-硬件连接》接好手套，并按《03-基站使用与配对》完成基站配对。
  第 3 节的演示模式不需要任何硬件，可以先用它确认可视化本身工作正常。

本章后面的命令都在可视化目录里执行，先进入该目录：

```bash
cd ~/revohuman-release/revohuman-0.1.0/simulation
```

## 2. 可视化是怎么工作的

```text
终端 1                                      终端 2
revohuman-live            ── 本机广播 ──▶   ./run_viewer.sh
打开手套与 Tracker，开始广播                 订阅广播并显示
```

- **先起哪一个都可以**。可视化先起时，窗口显示 `waiting for the SDK broadcast ...` 并列出终端 1 该执行的命令；
  广播一开始，窗口自动连上并显示双手。
- **SDK 退出时窗口不退出**：画面停在最后一帧并变暗，顶部横幅写明断开原因；
  重新启动 `revohuman-live` 后自动接上。
- 同一时间只能有一个 `revohuman-live` 在广播；订阅方（可视化窗口）可以有多个。

## 3. 演示模式（不接手套）

不接任何硬件，用可视化内置的演示数据打开窗口：

```bash
./run_viewer.sh --demo P1
```

`--demo` 后面的 `P1` 不要省略，它指定演示的型号。

窗口打开后应看到：左侧两只手在空间里各自画小圈、上下起伏并缓慢转腕，脚下是地面网格；
右侧两只手固定摆放，手指小幅屈伸，旁边的关节角表随之变化。终端里会打印：

```text
[viewer] 演示广播 P1（left、right）
[viewer] SDK demo（pid 12345）：型号 P1（demo P1，识别来源 demo），left demo，right demo
[viewer] left 触觉：none (P1 has no tactile)
[viewer] right 触觉：none (P1 has no tactile)
[viewer] 笛卡尔视图：tracker {'left': 'DEMO-L', 'right': 'DEMO-R'}
[revohuman_sim] 场景就绪（0.3 s）
```

P1 没有触觉传感器，`触觉：none (P1 has no tactile)` 是正常提示。

关闭窗口或在终端按 `Ctrl+C` 退出，退出时终端打印本次的帧数与刷新率，例如
`[view] 窗口关闭：3580 帧 / 60.0s（59.7 fps）`。

只看一只手的演示时加 `--demo-hands left`（或 `right`）。

## 4. 接真手套

需要两个终端。

### 4.1 终端 1：启动广播

```bash
revohuman-live
```

启动约需半分钟（要等基站数据与 Tracker 的首帧位姿），期间依次打印：

```text
[live] 型号 P1（编码器手套 + tracker，识别来源 sn），left /dev/ttyACM0，right /dev/ttyACM1
[revohuman.live] 打开 tracker {...}（基站门 flag 档；等基站数据与首帧位姿，可能要十几秒）
...
[live] tracker：已打开 {...}
[live] 广播中：/run/user/1000/revohuman/live.sock（Ctrl+C 退出）
```

看到 `广播中：` 即表示广播就绪（路径里的 `1000` 是当前用户的 uid，因人而异）。
串口编号 `/dev/ttyACM0`、`/dev/ttyACM1` 与手别的对应关系由 SDK 自动识别，以实际打印为准。

`revohuman-live` 与 `python3 -m revohuman live` 完全等价。只开一只手、不开 Tracker 等参数见《04-数据录制》。

### 4.2 终端 2：打开可视化

```bash
cd ~/revohuman-release/revohuman-0.1.0/simulation
./run_viewer.sh
```

窗口连上广播后，左侧笛卡尔视图里两只手的相对位置与朝向应与真手一致，右侧手指随真手屈伸。

退出时先在终端 2 关窗口（或按 `Ctrl+C`），再在终端 1 按 `Ctrl+C` 停止广播；反过来也可以。

### 4.3 一键自检

不开窗口、在一个终端里完成「启动广播 → 可视化接收 10 秒 → 停止广播」，用来确认整条链路正常：

```bash
cd ~/revohuman-release/revohuman-0.1.0/simulation
revohuman-live > ~/revohuman-live.log 2>&1 &
LIVE=$!
./run_viewer.sh --headless --wait 60 --seconds 10 --snapshot ~/viewer-check.png
kill $LIVE
wait $LIVE
```

`--wait 60` 让可视化最多等 60 秒广播就绪。正常时可视化的输出末尾是：

```text
[left] /dev/ttyACM0：2002 帧 / 10.0s（200.1 Hz），带触觉 0 帧，valid_mask=0x1fffff
[left] 触觉：none (P1 has no tactile)
[left] 笛卡尔：live  掌根 xyz +0.052 +0.069 +0.039 m  rpy -129.5 +58.4 +114.3°
[right] /dev/ttyACM1：2001 帧 / 10.0s（200.0 Hz），带触觉 0 帧，valid_mask=0x1fffff
[right] 触觉：none (P1 has no tactile)
[right] 笛卡尔：live  掌根 xyz +0.149 +0.137 +0.038 m  rpy +168.1 +56.5 -81.7°
[viewer] 快照 → /home/<用户名>/viewer-check.png
```

判断标准：

- 两只手各约 **200 Hz**；
- 两只手都是 `笛卡尔：live`（位置与姿态数值随手的摆放而不同）；
- 命令没有报错退出。

两个视图的截图存在 `~/viewer-check.png`，广播端的日志在 `~/revohuman-live.log`。

## 5. 无窗口模式

没有显示器的机器（例如通过 SSH 登录）不能开窗口，可以用无窗口模式：运行指定的秒数后打印统计，
并把两个视图存成一张图片。用演示数据试一次：

```bash
./run_viewer.sh --demo P1 --headless --seconds 5 --snapshot ~/viewer-demo.png
```

输出末尾应有：

```text
[left] demo：489 帧 / 5.0s（97.7 Hz），带触觉 0 帧，valid_mask=0x1fffff
[left] 触觉：none (P1 has no tactile)
[left] 笛卡尔：live  掌根 xyz +0.313 +0.131 +1.089 m  rpy +31.5 -0.0 +6.1°
[right] demo：489 帧 / 5.0s（97.7 Hz），带触觉 0 帧，valid_mask=0x1fffff
[right] 触觉：none (P1 has no tactile)
[right] 笛卡尔：live  掌根 xyz +0.386 -0.210 +1.051 m  rpy +6.4 -0.0 -16.7°
[viewer] 快照 → /home/<用户名>/viewer-demo.png
```

演示数据约 100 Hz，真手套约 200 Hz。接真手套时去掉 `--demo P1`，并先启动广播（见第 4 节）。

无窗口模式的退出码：

| 退出码 | 含义 |
|---|---|
| `0` | 正常 |
| `2` | 启动失败、`--wait` 秒内没连上广播，或运行期间没收到手套数据 |

## 6. 常用参数

`./run_viewer.sh --help` 列出全部参数，常用的有：

| 参数 | 作用 |
|---|---|
| `--demo P1` | 不接硬件，显示内置的 P1 演示数据 |
| `--demo-hands left\|right\|both` | 演示数据里有哪几只手（默认 `both`） |
| `--view split\|cart\|fixed` | 启动时的布局：双视图 / 只看笛卡尔视图 / 只看固定基座视图（默认 `split`，运行中按 `V` 切换） |
| `--tracker off` | 笛卡尔视图不画手（显示 `no pose: off (--tracker off)`），只看手指关节；可再加 `--view fixed` 只留固定基座视图。广播端仍会打开 Tracker；要广播端也不开 Tracker，见《04-数据录制》 |
| `--lite` | 关闭阴影与反射，没有独立显卡或画面卡顿时使用 |
| `--fps N` | 窗口刷新率上限（默认 60） |
| `--spacing M` | 固定基座视图里两只手的间距，单位米（默认 0.27） |
| `--headless` | 无窗口模式 |
| `--seconds S` | 无窗口模式运行的秒数 |
| `--wait S` | 无窗口模式最多等广播多少秒（默认 10） |
| `--snapshot 文件` | 无窗口模式结束时把两个视图存成 PNG |
| `--urdf-dir 目录` | 手部模型所在目录（含 `urdf/` 与 `meshes/`），默认源码包根目录的 `description/` |
| `--size 宽x高` | 截图尺寸（默认 `1600x800`） |
| `--socket 路径` | 广播地址。默认与 `revohuman-live` 使用同一个，一般不需要设置 |

终端里的日志按级别分颜色：警告黄色、错误红色，普通信息不上色；输出重定向到文件时不带颜色。
可视化与 `revohuman-live` 认同一个环境变量 `REVOHUMAN_LOG_COLOR`（`auto` / `always` / `never`），
例如 `REVOHUMAN_LOG_COLOR=never ./run_viewer.sh` 关闭颜色，详见《07-日志与错误码》第 1.1 节。

## 7. 窗口操作

| 操作 | 作用 |
|---|---|
| `V` | 切换布局：双视图 → 只看笛卡尔视图 → 只看固定基座视图 |
| `F` | 笛卡尔视图的镜头跟随两掌中点（开 / 关；拖动平移时自动关闭） |
| `C` | 两个视图的镜头复位，并重新打开跟随 |
| `Tab` | 切换关节角表显示哪只手 |
| 鼠标左键拖动 | 旋转镜头 |
| 鼠标右键拖动 | 平移镜头 |
| 鼠标滚轮 | 缩放 |

鼠标操作作用在鼠标所在的那个视图上。

## 8. 画面上的信息

**笛卡尔视图（左）**

- 左上角：每只手的状态（`live` 或 `LOST`）、位姿的新鲜度（`age`）、掌根位置 `xyz`（米）与姿态 `rpy`（度）。
- 每只手画出掌根坐标轴与到地面的垂线，地面网格间距 0.1 米。
- 左下角：两只 Tracker 的序列号、基站检查结果（正常时为 `geometry ok`）、镜头跟随状态。
  广播端的 Tracker 停止输出位姿时，基站检查结果换成 `tracker stopped: …`（见第 9 节）。
- 超过 0.5 秒没有新位姿的手（例如 Tracker 被遮挡）停在最后的位置、半透明显示并标 `LOST`，
  重新看到基站后自动恢复为 `live`。
- 世界坐标系 z 轴朝上，**原点与水平朝向取决于基站的摆放与标定，本身没有物理意义**；
  两只手之间的相对位置与朝向是真实的。

**固定基座视图（右）**

- 关节角表：`fw deg` 是手套上报的关节角，`urdf deg` 是换算到手模型上的角度（画面上的手按这一列摆）。
- 底部：型号与识别方式，以及每只手的串口、刷新率（约 200 fps）、数据新鲜度和无效通道（正常为 `invalid none`）。
- `tactile none (P1 has no tactile)`：P1 没有触觉传感器，属正常提示。

**与广播断开时**：两个视图变暗，顶部横幅 `SDK DISCONNECTED - …` 写明原因，画面保持最后一帧。

## 9. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 启动时报 `手部模型（URDF）尚未随本发布包提供（URDF is coming soon）` | 手部模型即将提供，还不在本发布包内；URDF 就位后放到源码包根目录的 `description/`，或用 `--urdf-dir` 指定（见本章开头）。数据采集与录制不受影响 |
| 启动时报 `手部模型目录不完整` | 模型目录下要有 `urdf/`（其中恰好一份 `.urdf` 文件）与 `meshes/` 两个子目录 |
| 窗口一直显示 `waiting for the SDK broadcast ...` | 广播没有启动，或还在启动中（约半分钟）。确认终端 1 已打印 `广播中：`；若已打印，对比窗口里列出的 `socket:` 路径与终端 1 打印的路径是否一致 |
| 终端 1 报 `上已经有一个广播在运行` | 另一个 `revohuman-live` 还开着，先关掉它 |
| 终端 1 报 `手套串口被别的程序占着` | 录制程序或另一个 `revohuman-live` 正在使用手套；同一时间只能有一个程序打开手套，先关掉它 |
| 终端 1 报 `当前用户没有手套串口的读写权限` | 按《01-环境安装与系统要求》第 5 节加入 `dialout` 组，并注销后重新登录 |
| `revohuman-live: command not found` | `~/.local/bin` 不在 `PATH` 里：打开一个新终端再试（见《01-环境安装与系统要求》第 7 节），或改用 `python3 -m revohuman live` |
| 笛卡尔视图显示 `no pose: pysurvive not installed` | 广播端找不到 Tracker 驱动，按《01-环境安装与系统要求》第 6 节安装。此时右侧视图照常工作 |
| 笛卡尔视图显示 `no pose: tracker in use by another process` | Tracker 正被别的程序使用，关掉它后重启 `revohuman-live` |
| 笛卡尔视图左下角出现 `startup gate: …` 或 `geometry: … issue(s)` | 基站检查没有通过，此时两只手的相对位姿不一定可信。看终端 1 的日志，按《03-基站使用与配对》处理 |
| 某只手半透明并标 `LOST` | 该手的 Tracker 超过 0.5 秒没有新位姿，通常是被遮挡或离开了基站视野；重新看到基站后自动恢复 |
| 两只手都标 `LOST`，左下角出现 `tracker stopped: …` | 广播端的 Tracker 已停止输出位姿（例如基站被挪动、Tracker 全部掉线），不会自动恢复；右侧视图照常工作。终端 1 会打印 `tracker 已停：…`，按终端 1 里 Tracker 的报错处理（《03-基站使用与配对》第 7 节）后重新启动 `revohuman-live` |
| 双手在笛卡尔视图里离网格原点很远，或朝向不直观 | 世界原点与朝向取决于基站，没有物理意义；按 `C` 复位镜头，按 `F` 打开跟随 |
| 启动时报 `GLFW 初始化失败（没有图形界面？可以用 --headless --snapshot）` | 当前会话没有图形界面（例如通过 SSH 登录），改用第 5 节的无窗口模式 |
| 无窗口模式报错退出，错误信息里有 `eglQueryString` 或 `glGetError` | 缺少 OpenGL 运行库：执行 `sudo apt install -y libegl1 libgl1`（《01-环境安装与系统要求》第 4 节） |
| `run_viewer.sh` 报 `依赖安装失败（网络 / 镜像？…）` | 首次运行要从 PyPI 下载依赖。国内网络在命令前加 `PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/` 后重试 |
| 窗口画面卡顿 | 加 `--lite` 关闭阴影与反射 |
| 报 `unsupported broadcast schema` | 可视化与 SDK 来自不同版本的发布包，两边换成同一个发布包 |
