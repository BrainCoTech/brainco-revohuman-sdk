# 05 仿真与可视化

源码包的 `simulation/` 目录里有一个三维可视化程序，在一个窗口里实时显示一副 P1 手套：

| 视图 | 内容 |
|---|---|
| 左：笛卡尔视图 | 双手按 Tracker 给出的位置与姿态摆在同一个世界坐标系里，手指随关节角一起动；左上角列出位姿四元数 |
| 右：固定基座视图 | 两只手固定摆放，只看手指关节；左上角列出关节角表 |

数据来自 SDK 的本机广播：命令 `revohuman-live` 打开手套与 Tracker，把关节角与位姿广播给本机的订阅方；
可视化只订阅这路广播，**不直接访问手套和 Tracker**。因此两者分开启动、分开退出，
也可以同时开多个可视化窗口看同一路广播。

## 1. 开始之前

- 已按《01-环境安装与系统要求》执行完全部步骤，包括第 9 节「安装三维可视化环境」；
  或者按《01》第 11 节一键安装到了虚拟环境。用虚拟环境时，第 4.1 节的 `run_sim_host.sh` 会自动使用它；
  在终端里直接运行 `revohuman-live`（第 4.2 节）前，要先 `source ~/.venvs/revohuman_sdk/bin/activate`。
- 使用真手套时，还需要按《02-硬件连接》接好手套，并按《03-基站使用与配对》完成基站配对。
  第 3 节的演示模式不需要任何硬件，可以先用它确认可视化本身工作正常。

本章后面的命令都在可视化目录里执行，先进入该目录：

```bash
cd ~/revohuman-release/revohuman-0.1.2/simulation
```

## 2. 可视化是怎么工作的

```text
终端 1                                      终端 2
revohuman-live            ── 本机广播 ──▶   ./run_viewer.sh
打开手套与 Tracker，开始广播                 订阅广播并显示
```

- **先起哪一个都可以**。可视化先起时，窗口显示 `waiting for the SDK broadcast ...` 并列出终端 1 该执行的命令；
  广播一开始，窗口自动连上并显示双手。
- **SDK 退出时窗口不退出**：画面停在最后一帧并变暗，顶部横幅写明断开原因；
  重新启动 `revohuman-live` 后自动接上。
- 同一时间只能有一个 `revohuman-live` 在广播；订阅方（可视化窗口）可以有多个。
- 不想开两个终端时，用第 4.1 节的 `run_sim_host.sh` 一条命令把两者一起拉起、一起退出。

## 3. 演示模式（不接手套）

不接任何硬件，用可视化内置的演示数据打开窗口：

```bash
./run_viewer.sh --demo P1
```

`--demo` 后面的 `P1` 不要省略，它指定演示的型号。

窗口打开后应看到：左侧两只手在空间里各自画小圈、上下起伏并缓慢转腕，脚下是地面网格；
右侧两只手固定摆放，手指小幅屈伸，左上角的关节角表随之变化。终端里会打印：

```text
[viewer] 演示广播 P1（left、right）
[viewer] SDK demo（pid 12345）：型号 P1（demo P1，识别来源 demo），left demo，right demo
[viewer] left 触觉：none (P1 has no tactile)
[viewer] right 触觉：none (P1 has no tactile)
[viewer] 笛卡尔视图：tracker {'left': 'DEMO-L', 'right': 'DEMO-R'}
[revohuman_sim] 场景就绪（0.1 s）
```

P1 没有触觉传感器，`触觉：none (P1 has no tactile)` 是正常提示。

关闭窗口或在终端按 `Ctrl+C` 退出，退出时终端打印本次的帧数与刷新率，例如
`[view] 窗口关闭：3580 帧 / 60.0s（59.7 fps）`。

只看一只手的演示时加 `--demo-hands left`（或 `right`）。

## 4. 接真手套

### 4.1 一条命令启动

```bash
cd ~/revohuman-release/revohuman-0.1.2/simulation
./run_sim_host.sh
```

脚本先在后台启动广播 `revohuman-live`，等广播就绪（约半分钟，要等基站数据与 Tracker 的首帧位姿）后打开可视化窗口；
等待期间广播端的输出同步显示在终端里。最多等 90 秒（环境变量 `REVOHUMAN_SIM_WAIT` 可改秒数），到时广播还没就绪就先打开窗口，
广播就绪后窗口自动连上。窗口连上广播后，左侧笛卡尔视图里两只手的相对位置与朝向应与真手一致，右侧手指随真手屈伸。

- **关闭窗口、按 `Ctrl+C` 或关掉终端**，脚本一并停止它启动的广播。
- 广播端的输出写到日志 `~/.local/state/revohuman/sim_live.log`。广播没能启动时（例如手套被别的程序占着），
  脚本打印日志的最后几行后退出，按其中的报错处理（见第 9 节）。
- 本机已经有一个广播在运行（另一个终端里、或容器里的 `revohuman-live`）时，脚本不另起广播，只打开窗口显示它的数据，
  并打印 `检测到已有后端在运行（pid …，型号 …，手 …，socket …），只启动可视化`。这时关闭窗口不会停止那个广播；
  `--hands`、`--product` 与 `--` 之后的参数只在启动广播时起作用，这次不起作用（脚本会提示），要换设置先停掉那个广播。
- 脚本按以下顺序找 SDK：`--venv` 指定的虚拟环境 → 《01》第 11 节建的 `~/.venvs/revohuman_sdk`
  （或环境变量 `REVOHUMAN_VENV` 指定的目录，存在才用）→ 当前终端的 `python3`（按《01》第 3–10 节装到用户目录的属于这种）。
  都找不到时提示先运行 `install_venv.sh` 并退出。用虚拟环境的不必先激活。

不接手套时，可以先用演示数据确认脚本本身可用（演示模式不启动广播，也不需要 SDK）：

```bash
./run_sim_host.sh --demo P1 --headless --seconds 2 --snapshot ~/sim-demo.png
```

输出与第 5 节相同，最后一行是 `[viewer] 快照 → /home/<用户名>/sim-demo.png`。

常用选项（全部选项见 `./run_sim_host.sh --help`）：

| 选项 | 作用 |
|---|---|
| `--hands left\|right\|both` | 只开一只手（默认 `both`） |
| `--product auto\|P1\|PTV1` | 指定型号（默认 `auto`，自动识别） |
| `--no-tracker` | 广播端不开 Tracker，笛卡尔视图不画手，只看手指关节 |
| `--demo [P1\|PTV1]` | 不启动广播，只看演示数据（同第 3 节）；不写型号时按 `--product`，都没给就是 PTV1 |
| `--log 文件` | 广播端日志的位置（默认 `~/.local/state/revohuman/sim_live.log`，设了 `XDG_STATE_HOME` 时在 `$XDG_STATE_HOME/revohuman/` 下；每次追加） |
| `--venv 目录` | SDK 所在的虚拟环境；`--venv none` 表示直接用当前终端的 `python3` |
| `--socket 路径` | 广播的 socket，广播与可视化用同一个（默认按固定规则找，一般不用设） |

其余参数原样交给可视化，第 6 节的参数都可以直接加在后面，例如 `./run_sim_host.sh --lite`；
`--` 之后的参数交给 `revohuman-live`。

### 4.2 分两个终端启动

广播与可视化也可以分开启动、分开退出，需要两个终端。

**终端 1：启动广播**

```bash
revohuman-live
```

启动约需半分钟（要等基站数据与 Tracker 的首帧位姿），期间依次打印：

```text
[live] 型号 P1（编码器手套 + tracker，识别来源 sn），left /dev/ttyACM0，right /dev/ttyACM1
[revohuman.live] 打开 tracker {...}（基站门 flag 档；等基站数据与首帧位姿，可能要十几秒）
...
[live] tracker：已打开 {...}
[live] 广播中：/run/user/1000/revohuman/live.sock（Ctrl+C 退出）
```

看到 `广播中：` 即表示广播就绪（路径里的 `1000` 是当前用户的 uid，因人而异）。
串口编号 `/dev/ttyACM0`、`/dev/ttyACM1` 与手别的对应关系由 SDK 自动识别，以实际打印为准。

`revohuman-live` 与 `python3 -m revohuman live` 完全等价。只开一只手、不开 Tracker 等参数见《04-数据录制》。

**终端 2：打开可视化**

```bash
cd ~/revohuman-release/revohuman-0.1.2/simulation
./run_viewer.sh
```

退出时先在终端 2 关窗口（或按 `Ctrl+C`），再在终端 1 按 `Ctrl+C` 停止广播；反过来也可以。

### 4.3 一键自检

不开窗口、在一个终端里完成「启动广播 → 可视化接收 10 秒 → 停止广播」，用来确认整条链路正常：

```bash
cd ~/revohuman-release/revohuman-0.1.2/simulation
./run_sim_host.sh --headless --seconds 10 --snapshot ~/viewer-check.png
```

`--headless --seconds 10 --snapshot` 交给可视化：不开窗口，接收 10 秒后存图退出；可视化退出后脚本停止广播。正常时输出末尾是：

```text
[left] /dev/ttyACM0：2004 帧 / 10.0s（200.0 Hz），带触觉 0 帧，valid_mask=0x1fffff
[left] 手套时间戳：最近采样刻 1791977031.930631，到达延迟 8.0 ms（最近 1 s 中位数）
[left] 触觉：none (P1 has no tactile)
[left] 笛卡尔：live  palm_link xyz +0.183 +0.492 +0.156 m  rpy -159.1 +61.5 -67.8°
[left] 位姿：2347 帧 / 10.0s（234.2 Hz），四元数 w +0.2286   x +0.9693   y +0.0110   z +0.0905，最近采样刻 1791977031.940243，到达延迟 0.5 ms（最近 1 s 中位数；含主机固定开销、不含 Tracker 打包延迟）
[right] /dev/ttyACM1：2004 帧 / 10.0s（200.0 Hz），带触觉 0 帧，valid_mask=0x1fffff
[right] 手套时间戳：最近采样刻 1791977031.930516，到达延迟 8.4 ms（最近 1 s 中位数）
[right] 触觉：none (P1 has no tactile)
[right] 笛卡尔：live  palm_link xyz +0.039 +0.505 +0.154 m  rpy +145.7 +74.9 -111.1°
[right] 位姿：2354 帧 / 10.0s（234.9 Hz），四元数 w -0.1164   x -0.9848   y -0.1135   z +0.0611，最近采样刻 1791977031.940950，到达延迟 0.6 ms（最近 1 s 中位数；含主机固定开销、不含 Tracker 打包延迟）
[viewer] 快照 → /home/<用户名>/viewer-check.png
[run_sim_host] 停止广播（pid 12345）
```

判断标准：

- 两只手套各约 **200 Hz**；
- 两只手都是 `笛卡尔：live`，且各有一行 `位姿：`（位置、姿态与四元数随手的摆放而不同）；
- 手套的到达延迟是几毫秒量级（上例约 8 ms）；位姿的到达延迟比手套小得多（上例 0.5–0.6 ms，原因见第 8 节）；
- 命令没有报错退出。

两个视图的截图存在 `~/viewer-check.png`，广播端的日志在 `~/.local/state/revohuman/sim_live.log`。

## 5. 无窗口模式

没有显示器的机器（例如通过 SSH 登录）不能开窗口，可以用无窗口模式：运行指定的秒数后打印统计，
并把两个视图存成一张图片。用演示数据试一次：

```bash
./run_viewer.sh --demo P1 --headless --seconds 5 --snapshot ~/viewer-demo.png
```

输出末尾应有：

```text

[left] 手套时间戳：最近采样刻 1791976299.250077，到达延迟 0.0 ms（最近 1 s 中位数）
[left] 触觉：none (P1 has no tactile)
[left] 笛卡尔：live  palm_link xyz +0.305 +0.137 +1.090 m  rpy +32.7 +0.0 +8.4°
[left] 位姿：244 帧 / 5.0s（48.8 Hz），四元数 w +0.6691   x -0.4432   y +0.5510   z -0.2287，最近采样刻 1791976299.239952，到达延迟 0.0 ms（最近 1 s 中位数）
[right] demo：489 帧 / 5.0s（97.7 Hz），带触觉 0 帧，valid_mask=0x1fffff
[right] 手套时间戳：最近采样刻 1791976299.250124，到达延迟 0.0 ms（最近 1 s 中位数）

[viewer] 快照 → /home/<用户名>/viewer-demo.png
```

演示数据约 100 Hz，真手套约 200 Hz。演示数据的采样时刻与到达时刻是同一刻，到达延迟恒为 0.0 ms。接真手套时去掉 `--demo P1`，并先启动广播（见第 4 节）。

无窗口模式的退出码：

| 退出码 | 含义 |
|---|---|
| `0` | 正常 |
| `2` | 启动失败、`--wait` 秒内没连上广播，或运行期间没收到手套数据 |
| `3` | 触觉开着，但运行期间没收到触觉帧 |
| `130` | 被 `Ctrl-C` 打断 |

## 6. 常用参数

`./run_viewer.sh --help` 列出全部参数（还没建过可视化环境时会先把它建好，见《01-环境安装与系统要求》第 9 节），常用的有：

| 参数 | 作用 |
|---|---|
| `--demo P1` | 不接硬件，显示内置的 P1 演示数据 |
| `--demo-hands left\|right\|both` | 演示数据里有哪几只手（默认 `both`） |
| `--view split\|cart\|fixed` | 启动时的布局：双视图 / 只看笛卡尔视图 / 只看固定基座视图（默认 `split`，运行中按 `V` 切换） |
| `--tracker off` | 笛卡尔视图不画手（显示 `no pose: off (--tracker off)`），只看手指关节；可再加 `--view fixed` 只留固定基座视图。广播端仍会打开 Tracker；要广播端也不开 Tracker，用第 4.1 节的 `--no-tracker`（自己启动广播时见《04-数据录制》第 7 节） |
| `--lite` | 关闭阴影与反射，没有独立显卡或画面卡顿时使用 |
| `--fps N` | 窗口刷新率上限（默认 60） |
| `--spacing M` | 固定基座视图里两只手的间距，单位米（默认 0.30） |
| `--headless` | 无窗口模式 |
| `--seconds S` | 无窗口模式运行的秒数 |
| `--wait S` | 无窗口模式最多等广播多少秒（默认 10） |
| `--snapshot 文件` | 无窗口模式结束时把两个视图存成 PNG |
| `--urdf-dir 目录` | 手部模型所在目录（含 `urdf/` 与 `meshes/`），默认源码包根目录的 `description/` |
| `--size 宽x高` | 截图尺寸（默认 `1600x800`） |
| `--socket 路径` | 广播地址。默认与 `revohuman-live` 使用同一个，一般不需要设置 |

触觉热力图与排查用的参数：

| 参数 | 作用 |
|---|---|
| `--tactile off` | 不画触觉热力图。默认 `auto`：型号带触觉、且这只手识别到了触觉时才画 |
| `--scale N` | 色标满量程；默认 `0` 为自动（保持峰值并缓慢回落） |
| `--contact N` | 接触阈值，读数低于它的区域不画（默认 20，与触觉读数同单位） |
| `--threshold N` | 手指统计与点表只计读数高于它的点（默认 0） |
| `--top N` | 按 `Insert` 或无窗口模式打印的点表行数（默认 20） |
| `--no-heat-ring` | 不画接触圈 |
| `--cam 方位角,仰角,距离` | 固定基座视图的初始镜头 |
| `--layout 文件` | 触觉布局 yaml，默认用随包的布局 |
| `--refit` | 忽略缓存与随包的贴点表，按模型网格重新拟合触觉点位置 |
| `--dump-layout 文件` | 无窗口模式结束时把触觉点的位置与读数存成 JSON（每只手一个文件，文件名加 `_left` / `_right`） |
| `--no-bulk` | 热斑逐个写入场景（排查渲染问题时用，会变慢） |

热斑形状的微调参数（`--heat-pitch-mm`、`--heat-sigma-mm` 等）见 `./run_viewer.sh --help`，一般不需要改。

终端里的日志按级别分颜色：警告黄色、错误红色，普通信息不上色；输出重定向到文件时不带颜色。
可视化与 `revohuman-live` 认同一个环境变量 `REVOHUMAN_LOG_COLOR`（`auto` / `always` / `never`），
例如 `REVOHUMAN_LOG_COLOR=never ./run_viewer.sh` 关闭颜色，详见《07-日志与错误码》第 1.1 节。

## 7. 窗口操作

| 操作 | 作用 |
|---|---|
| `V` | 切换布局：双视图 → 只看笛卡尔视图 → 只看固定基座视图 |
| `F` | 笛卡尔视图的镜头跟随两掌中点（开 / 关；拖动平移时自动关闭） |
| `C` | 两个视图的镜头复位，并重新打开跟随 |
| 鼠标左键拖动 | 旋转镜头 |
| 鼠标右键拖动 | 平移镜头 |
| 鼠标滚轮 | 缩放 |

鼠标操作作用在鼠标所在的那个视图上。

PTV1 画触觉热力图时另有这些按键（作用在固定基座视图）：

| 按键 | 作用 |
|---|---|
| `J` | 左上角的表格在关节角与触觉统计之间切换 |
| `Tab` | 触觉统计显示哪只手（双手时） |
| `←` / `→` | 选中上一个 / 下一个触觉点 |
| `PgUp` / `PgDn` | 跳到上一根 / 下一根手指 |
| `↑` / `↓` | 放大 / 缩小色标量程（改为固定量程） |
| `Home` | 以当前读数作为触觉基线，之后显示减去基线的值 |
| `Delete` | 清除基线 |
| `Insert` | 把当前这只手的触觉点表打印到终端 |

## 8. 画面上的信息

画面上只显示五类数据：数据帧率、实时关节角、位姿四元数、采样时间戳、到达延迟。行首的 `L` / `R` 表示左手 / 右手。

**笛卡尔视图（左）**

- 左上角 `L quat` / `R quat`：每只手 Tracker 位姿的四元数，按 `w x y z` 排列，与 SDK 输出的 Tracker 位姿四元数同序。
- 左下角 `L pose` / `R pose`：每只手位姿数据的帧率、采样时间戳 `sample` 与到达延迟 `latency`。
- 每只手画出 palm_link 坐标轴与到地面的垂线，地面网格间距 0.1 米。
- 超过 0.5 秒没有新位姿的手（例如 Tracker 被遮挡）停在最后的位置、半透明显示，
  四元数后面标 `LOST` 和已经断开的秒数；重新看到基站后自动恢复。
- 世界坐标系 z 轴朝上，**原点与水平朝向取决于基站的摆放与标定，本身没有物理意义**；
  两只手之间的相对位置与朝向是真实的。

**固定基座视图（右）**

- 左上角关节角表：每个关节一行，`L deg` / `R deg` 两列是左右手套上报的关节角（度），`--` 表示还没收到有效读数。
- 左下角 `L glove` / `R glove`：每只手套数据的帧率（约 200 Hz）、采样时间戳 `sample` 与到达延迟 `latency`。

**时间戳与延迟**

- `sample` 是这一帧数据的采样时刻，以 Unix 时间的秒数显示（精确到微秒），与 SDK 输出的采样时间戳是同一个值。
- `latency` 是 SDK 收到这一帧的时刻减去采样时刻，取最近 1 秒内的中位数。
- Tracker 位姿的 `latency` 行尾标 `(excl. pack delay)` 时，不含 Tracker 内部的打包延迟，比真实的到达延迟小；
  用它看抖动和停顿，不要当作端到端延迟。
- 还没收到数据时这一行显示 `no data yet`；拿不到采样时间戳时显示 `--`。

**出问题时**：只在出问题时多出一行以 `!!` 开头的说明，例如广播端的 Tracker 停止输出位姿时显示
`tracker stopped: …`，基站检查没有通过时显示 `startup gate: …` 或 `geometry: … issue(s)`（见第 9 节）。
广播端没有启用 Tracker 时，左下角显示 `pose none: <原因>`。

**与广播断开时**：两个视图变暗，顶部横幅 `SDK DISCONNECTED - …` 写明原因，画面保持最后一帧。

## 9. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 启动时报 `找不到手部模型目录` | 源码包根目录下的 `description/`（手部模型）被移走或删除了：重新解压源码包，或用 `--urdf-dir` 指定手部模型所在目录 |
| 启动时报 `手部模型目录不完整` | 模型目录下要有 `urdf/`（其中恰好一份 `.urdf` 文件）与 `meshes/` 两个子目录 |
| 窗口一直显示 `waiting for the SDK broadcast ...` | 广播没有启动，或还在启动中（约半分钟）。确认终端 1 已打印 `广播中：`；若已打印，对比窗口里列出的 `socket:` 路径与终端 1 打印的路径是否一致 |
| `run_sim_host.sh` 打印广播日志的最后几行后退出 | 广播没能启动。按日志里的报错查本表其余各行（下面「终端 1 报 …」的几行同样适用）；完整日志在 `~/.local/state/revohuman/sim_live.log` |
| `run_sim_host.sh` 等了 90 秒广播还没就绪，先打开了窗口 | 广播还在等基站数据或 Tracker 的首帧位姿：就绪后窗口自动连上；一直连不上时看日志 `~/.local/state/revohuman/sim_live.log` 停在哪一步，基站相关的按《03-基站使用与配对》处理 |
| 窗口打开后终端打印 `广播已退出，窗口不再更新` | 广播端中途退出了，窗口停在最后一帧。按随后打印的日志行处理，再重新执行 `run_sim_host.sh` |
| `run_sim_host.sh` 提示先运行 `install_venv.sh` | 没找到 SDK：按《01》第 11 节运行 `install_venv.sh`，或用 `--venv` 指向已装好 SDK 的虚拟环境；按《01》第 3–10 节安装的，确认 `python3 -c "import revohuman"` 不报错 |
| 终端 1 报 `上已经有一个广播在运行` | 另一个 `revohuman-live` 还开着，先关掉它 |
| 终端 1 报 `手套串口被别的程序占着` | 录制程序或另一个 `revohuman-live` 正在使用手套；同一时间只能有一个程序打开手套，先关掉它 |
| 终端 1 报 `当前用户没有手套串口的读写权限` | 按《01-环境安装与系统要求》第 5 节加入 `dialout` 组，并注销后重新登录 |
| `revohuman-live: command not found` | 用虚拟环境安装的：先 `source ~/.venvs/revohuman_sdk/bin/activate`。装到用户目录的：`~/.local/bin` 不在 `PATH` 里，打开一个新终端再试（见《01-环境安装与系统要求》第 7 节），或改用 `python3 -m revohuman live` |
| 笛卡尔视图显示 `pose none: pysurvive not installed` | 广播端找不到 Tracker 驱动，按《01-环境安装与系统要求》第 6 节安装。此时右侧视图照常工作 |
| 笛卡尔视图显示 `pose none: tracker in use by another process` | Tracker 正被别的程序使用，关掉它后重启 `revohuman-live` |
| 笛卡尔视图左下角出现 `!! startup gate: …` 或 `!! geometry: … issue(s)` | 基站检查没有通过，此时两只手的相对位姿不一定可信。看终端 1 的日志，按《03-基站使用与配对》处理 |
| 某只手半透明，四元数后面标 `LOST` | 该手的 Tracker 超过 0.5 秒没有新位姿，通常是被遮挡或离开了基站视野；重新看到基站后自动恢复 |
| 两只手都标 `LOST`，左下角出现 `!! tracker stopped: …` | 广播端的 Tracker 已停止输出位姿（例如基站被挪动、Tracker 全部掉线），不会自动恢复；右侧视图照常工作。终端 1 会打印 `tracker 已停：…`，按终端 1 里 Tracker 的报错处理（《03-基站使用与配对》第 7 节）后重新启动 `revohuman-live` |
| 双手在笛卡尔视图里离网格原点很远，或朝向不直观 | 世界原点与朝向取决于基站，没有物理意义；按 `C` 复位镜头，按 `F` 打开跟随 |
| 启动时报 `GLFW 初始化失败（没有图形界面？可以用 --headless --snapshot）` | 当前会话没有图形界面（例如通过 SSH 登录），改用第 5 节的无窗口模式 |
| 无窗口模式报错退出，错误信息里有 `eglQueryString` 或 `glGetError` | 缺少 OpenGL 运行库：执行 `sudo apt install -y libegl1 libgl1`（《01-环境安装与系统要求》第 4 节） |
| `run_viewer.sh` 报 `依赖安装失败（网络 / 镜像？…）` | 首次运行要从 PyPI 下载依赖。国内网络在命令前加 `PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/` 后重试 |
| 窗口画面卡顿 | 加 `--lite` 关闭阴影与反射 |
| 报 `unsupported broadcast schema` | 可视化与 SDK 的版本不一致：SDK 与源码包换成同一版本的发布文件 |
