# 01 环境安装与系统要求

本章从一台刚装好的 Ubuntu 22.04 开始，装齐 RevoHuman P1 需要的全部软件：
ROS 2 Humble、Tracker 驱动 libsurvive、RevoHuman SDK（含录制、基站蓝牙、三维可视化）以及 ROS 2 包。
按顺序执行即可，每一步都要做，不要跳过。

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Ubuntu 22.04 LTS，64 位（x86_64 或 aarch64） |
| Python | 系统自带的 Python 3.10（`/usr/bin/python3`）。SDK 只提供 Python 3.10 的安装包，其他版本的 Python（包括 conda / pyenv 装的）会被 pip 拒绝 |
| ROS 2 | Humble（本章第 3 节安装） |
| 账户 | 一个有 `sudo` 权限的普通用户 |
| USB | 每只手套占主机 1 个 USB 口，双手共 2 个；直接插主机，不要经过无源 HUB |
| 蓝牙 | 主机需要有可用的蓝牙适配器（读基站序列号与信道时使用） |
| 磁盘 | 安装约需 3 GB；录制数据另计，见《04-数据录制》 |
| 网络 | 安装过程需要访问 Ubuntu 软件源、ROS 软件源、PyPI 与 GitHub |

P1 手套每只手是一个手套单元：编码器手套的 MCU 与 Vive Tracker 挂在单元内的同一个 USB HUB 上，
主机经一根 USB 线看到这两个设备。硬件如何连接见《02-硬件连接》。

以下命令默认在普通用户的终端里执行；需要管理员权限的命令已写明 `sudo`。

## 2. 准备发布文件

发布包包含六个文件，把它们放进同一个目录（下文以 `~/revohuman-release` 为例）：

| 文件 | 内容 |
|---|---|
| `revohuman-0.1.0-cp310-cp310-linux_x86_64.whl` | SDK，x86_64 主机用 |
| `revohuman-0.1.0-cp310-cp310-linux_aarch64.whl` | SDK，aarch64（arm64）主机用 |
| `pysurvive-1.1.21+revohuman.1-cp310-cp310-linux_x86_64.whl` | Tracker 驱动 libsurvive，x86_64 主机用 |
| `pysurvive-1.1.21+revohuman.1-cp310-cp310-linux_aarch64.whl` | Tracker 驱动 libsurvive，aarch64（arm64）主机用 |
| `revohuman-0.1.0-bundle.tar.gz` | ROS 2 包、示例、文档、仿真、Docker 镜像构建文件 |
| `SHA256SUMS` | 校验和 |

进入该目录并校验文件完整性，每个文件都应显示 `OK`：

```bash
cd ~/revohuman-release
sha256sum -c SHA256SUMS
```

## 3. 安装 ROS 2 Humble

添加 ROS 2 软件源：

```bash
sudo apt update
sudo apt install -y software-properties-common curl gnupg lsb-release
sudo add-apt-repository -y universe
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null
```

> 国内网络访问 `packages.ros.org` 较慢时，可把上面的 `http://packages.ros.org/ros2/ubuntu`
> 换成 `https://mirrors.aliyun.com/ros2/ubuntu`，其余不变。

安装 ROS 2 与构建工具，并让每个新终端自动加载 ROS 环境：

```bash
sudo apt update
sudo apt install -y ros-humble-ros-base ros-dev-tools
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source /opt/ros/humble/setup.bash
```

## 4. 安装系统依赖

下面一次装齐 SDK、基站蓝牙与三维可视化所需的系统软件包：

```bash
sudo apt install -y python3-pip python3-venv bluez libgl1 libegl1
```

`python3-venv` 给三维可视化建独立的 Python 环境；`libgl1` 与 `libegl1` 是它的 OpenGL 运行库，两个都要装。

## 5. 设备权限

手套以串口 `/dev/ttyACM*` 出现，属于 `dialout` 组。把当前用户加入该组：

```bash
sudo usermod -aG dialout $USER
```

**加组之后要注销并重新登录**（或重启）才生效。

## 6. 安装 Tracker 驱动 libsurvive

Tracker 由开源驱动 libsurvive 读取，SDK 通过它的 Python 包 `pysurvive` 调用。
发布包附带了 **pysurvive 1.1.21+revohuman.1**：它基于上游 pysurvive 1.1.21（libsurvive `v1.01-21-gd89876a`），
加了两处修正——USB 传输超时后自动续收，Tracker 长时间被遮挡后重新见光即可恢复光学定位；
基站广播的重力读数抖动小于 2° 时保留基站几何（上游版本会把它清掉）。
**请安装附带的这一份，不要安装 PyPI 上的 `pysurvive==1.1.21`**：PyPI 上的 1.1.21 能通过自检，但没有上面两处修正；已经装过的机器照样执行下面的命令即可替换。
装其他版本号的 pysurvive 时，Tracker 的基站诊断会自检失败并降级：

```bash
cd ~/revohuman-release
python3 -m pip install --user --no-deps pysurvive-1.1.21+revohuman.1-cp310-cp310-linux_$(uname -m).whl
```

`--no-deps` 不能省：pysurvive 声明了一个图形界面依赖（wxPython），SDK 用不到，而它在 Linux 上通常装不上。

安装 Tracker 的设备访问规则，让普通用户可以读写 Tracker：

```bash
sudo tee /etc/udev/rules.d/81-revohuman-tracker.rules > /dev/null <<'RULES'
# Vive Tracker（USB 有线，28de:2300）
SUBSYSTEM=="usb", ATTRS{idVendor}=="28de", ATTRS{idProduct}=="2300", MODE="0666"
KERNEL=="hidraw*", SUBSYSTEM=="hidraw", ATTRS{idVendor}=="28de", ATTRS{idProduct}=="2300", MODE="0666"
RULES
```

使规则生效（已插着的 Tracker 需要重新插拔一次）：

```bash
sudo udevadm control --reload-rules && sudo udevadm trigger
```

## 7. 安装 RevoHuman SDK

按本机架构选择 wheel，一次装上 SDK 与录制、相机解码、基站蓝牙、三维可视化全部组件：

```bash
cd ~/revohuman-release
WHL=revohuman-0.1.0-cp310-cp310-linux_$(uname -m).whl
python3 -m pip install --user "$WHL[recording,camera,ble,viewer]"
```

> 国内网络访问 PyPI 较慢时，在上面的 `pip install` 后加 `-i https://mirrors.aliyun.com/pypi/simple/`。

SDK 的命令行工具装在 `~/.local/bin`，把它加入 `PATH`：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
export PATH="$HOME/.local/bin:$PATH"
```

## 8. 构建 ROS 2 包

解压源码包，把其中的 ROS 2 包放进工作空间并构建：

```bash
cd ~/revohuman-release
tar xzf revohuman-0.1.0-bundle.tar.gz
mkdir -p ~/ros2_ws/src
ln -s ~/revohuman-release/revohuman-0.1.0/ros2/* ~/ros2_ws/src/
cd ~/ros2_ws
colcon build --symlink-install
echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc
source ~/ros2_ws/install/setup.bash
```

解压出的 `~/revohuman-release/revohuman-0.1.0/` 下还有 `examples/`（示例程序）与 `simulation/`（三维可视化），
后面各章会用到。

## 9. 安装三维可视化环境

三维可视化在 `simulation/` 下自带一个独立的 Python 环境（`simulation/.venv`），与 SDK 互不影响。
执行一次启动器即可把它建好并装齐依赖（首次约 1–2 分钟，之后秒开）：

```bash
~/revohuman-release/revohuman-0.1.0/simulation/run_viewer.sh --help
```

> 国内网络访问 PyPI 较慢时，在命令前加 `PIP_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/`。

看到参数说明即表示环境已就绪。使用方法见《05-仿真与可视化》。

> **URDF is coming soon.** 可视化用到的手部模型（URDF）即将提供，暂不在本发布包内。
> 环境可以先建好；仿真与可视化要等 URDF 就位后才能使用，在此之前打开可视化会提示缺少手部模型并退出。

## 10. 检查安装结果

打开一个**新终端**（让 `~/.bashrc` 里的设置生效），逐条执行：

```bash
python3 -c "import revohuman, pysurvive, mcap, bleak, mujoco; print('revohuman', revohuman.__version__)"
python3 -m pip show pysurvive | grep Version
python3 -c "import pysurvive; print('libsurvive', pysurvive.survive_build_tag().decode())"
python3 -m revohuman --help
ros2 pkg list | grep revohuman
ros2 interface show revohuman_msgs/srv/Calibrate
```

应看到：

- 第一条打印 `revohuman 0.1.0`，没有 `ModuleNotFoundError`；
- `pip show` 显示 `Version: 1.1.21+revohuman.1`，下一条打印 `libsurvive v1.01-21-gd89876a+revohuman.1`；
- `ros2 pkg list` 列出 `revohuman_bringup`、`revohuman_msgs`、`revohuman_ros` 三个包。

接上手套后做一次体检（手套连接见《02-硬件连接》）：

```bash
python3 -m revohuman doctor
python3 -m revohuman product identify
```

体检通过时，`doctor` 显示 `fail=0`，并列出两个手套单元及其手别；`product identify` 显示 `型号 P1`。
