# 04 数据录制

本章用 SDK 把 P1 双手的关节角与 Tracker 位姿录成 MCAP 文件，读回检查，再导出为 CSV。
最后一节是实时广播命令 `revohuman-live` 的参数说明（《05-仿真与可视化》用它把实时数据送给三维可视化）。
用 ROS 2 录制见《06-ROS2》。

## 1. 录制前检查

逐项确认：

1. 已按《01-环境安装与系统要求》装好全部软件；
2. 两只手套已按《02-硬件连接》接好，`python3 -m revohuman doctor` 显示 `fail=0`；
3. 基站已按《03-基站使用与配对》写进白名单并标定过几何，且之后没有被移动；
4. 没有其他程序占着手套或 Tracker：`revohuman-live`、可视化的实时模式、ROS 2 节点都要先关掉。
   一只手套、一套 Tracker 驱动同一时刻只能被一个程序打开。

**零位**：Tracker 的位姿增量以「零位」为参照。录制程序启动时会按双手当时的位姿自动记一次零位，
所以启动前把双手摆到零位——每次录制都用同一个固定姿势（例如双手平放在桌面上的固定标记处）——
并保持不动，直到程序提示「零位已记下」。从运行命令到出现这句提示约 20 秒
（5 秒倒计时，加上打开手套与 Tracker、等基站与两只 Tracker 都就绪约 15 秒），这段时间里双手都不要动。

## 2. 录制脚本

把下面的脚本保存为 `~/revohuman_record.py`：

```python
"""RevoHuman P1 数据录制：打开双手手套与 Tracker，连续录若干段 MCAP。

用法：python3 ~/revohuman_record.py <输出目录> <每段秒数> <段数>
例：  python3 ~/revohuman_record.py ~/revohuman_data/demo 10 2
"""
import logging
import pathlib
import sys
import time

from revohuman import RevoHumanError, format_error, open_kit


def countdown(text: str, seconds: int) -> None:
    for n in range(seconds, 0, -1):
        print(f"{text}：{n}", flush=True)
        time.sleep(1)


def main() -> int:
    if len(sys.argv) != 4:
        print(__doc__, file=sys.stderr)
        return 2
    out_dir = pathlib.Path(sys.argv[1]).expanduser()
    seconds = float(sys.argv[2])
    episodes = int(sys.argv[3])
    out_dir.mkdir(parents=True, exist_ok=True)
    logging.basicConfig(level=logging.INFO,
                        format="%(asctime)s %(levelname)s %(name)s: %(message)s")

    countdown("双手摆到零位并保持不动", 5)
    try:
        kit = open_kit("P1")
    except RevoHumanError as exc:
        print(format_error(exc), file=sys.stderr)
        return 1

    aborted = 0
    with kit:
        ref = kit.tracker.reference
        print(f"零位已记下（{ref.calibration_id[:8]}），可以开始动作", flush=True)
        geometry = kit.geometry()
        if not geometry["ok"]:
            print(f"基站几何不达标：{geometry['errors']}；按《03-基站使用与配对》重新标定后再录",
                  file=sys.stderr)
            return 1
        rec = kit.recorder()
        try:
            for i in range(1, episodes + 1):
                if i > 1:
                    countdown("下一段即将开始", 3)
                path = out_dir / f"episode_{i:03d}.mcap"
                handle = rec.start(str(path), metadata={
                    "product": "P1", "episode": i, "reference": ref.to_payload()})
                print(f"[{i}/{episodes}] 录制中：{path}（{seconds:g} 秒，Ctrl-C 提前结束）", flush=True)
                stop_all = False
                try:
                    time.sleep(seconds)
                except KeyboardInterrupt:
                    stop_all = True
                s = handle.stop()
                print(f"[{i}/{episodes}] 已保存：{s['frames']} 帧，{s['bytes'] / 1e6:.2f} MB，"
                      f"{s['duration_sec']:.1f} 秒；各话题 {s['per_channel']}", flush=True)
                if s["aborted"]:
                    aborted += 1
                    print(f"[{i}/{episodes}] 本段已作废：{s['abort_reason']}", flush=True)
                if stop_all:
                    print("已按 Ctrl-C 停止录制", flush=True)
                    break
        except RevoHumanError as exc:
            print(format_error(exc), file=sys.stderr)
            return 1
        finally:
            rec.close()
    return 1 if aborted else 0


if __name__ == "__main__":
    sys.exit(main())
```

脚本的三个参数依次是输出目录、每段秒数、段数。每段存成一个文件 `episode_001.mcap`、`episode_002.mcap`……；
零位只在启动时记一次，同一次运行里的各段共用。按 `Ctrl-C` 会结束并保存当前这一段，然后退出。

录两段、每段 10 秒：

```bash
python3 ~/revohuman_record.py ~/revohuman_data/demo 10 2
```

输出类似（中间的 `INFO` 日志行从略）：

```text
双手摆到零位并保持不动：5
...
双手摆到零位并保持不动：1
零位已记下（019e0de4），可以开始动作
[1/2] 录制中：/home/<用户名>/revohuman_data/demo/episode_001.mcap（10 秒，Ctrl-C 提前结束）
[1/2] 已保存：11012 帧，1.65 MB，10.0 秒；各话题 {'/glove/right': 2002, '/tracker/right': 2505, '/tracker/left': 2501, '/paired': 2002, '/glove/left': 2002}
```

程序退出码：`0` 全部成功；`1` 打开失败、基站几何不达标或有段作废；`2` 参数不对。

## 3. 录制文件的内容

每个 `.mcap` 文件包含以下话题：

| 话题 | 帧类型 | 频率 | 内容 |
|---|---|---|---|
| `/glove/left`、`/glove/right` | `GloveFrame` | 200 Hz | 单只手的 21 个关节角 |
| `/paired` | `PairedFrame` | 200 Hz | 双手配对帧：同一硬件同步周期的左右两帧 |
| `/tracker/left`、`/tracker/right` | `TrackerFrame` | 约 250 Hz | Tracker 在基站坐标系中的位姿 |

主要字段：

| 帧 | 字段 | 说明 |
|---|---|---|
| `GloveFrame` | `joints_deg` | 21 个关节角，单位**度**；名称用 `revohuman.joint_map.joint_names()` 取 |
| `GloveFrame` | `joints_valid_mask` / `all_joints_valid` | 每个关节是否有效 |
| `GloveFrame` | `seq` / `generation` | 序号；`generation` 变化表示这只手的数据流中途重开过（重连、自检或双手同步重建之后） |
| `PairedFrame` | `left` / `right` / `skew_ns` | 左右两只手的 `GloveFrame`；`skew_ns` 为两手采样刻之差，硬件同步下恒为 0 |
| `TrackerFrame` | `pose.position` | 位置 `(x, y, z)`，单位**米** |
| `TrackerFrame` | `pose.rotation` | 姿态四元数，顺序 **`(w, x, y, z)`** |
| `TrackerFrame` | `serial` / `handedness` | Tracker 序列号 / 手别 |
| 全部 | `sample_wall_ns` | **采样刻**：传感器实际采样的时刻，Unix 时间纳秒 |
| 全部 | `recv_wall_ns` | **到达刻**：SDK 收到这一帧的时刻，含 USB 链路延迟 |

**时间戳**：做分析和跨手、跨设备对齐时一律用帧里的 `sample_wall_ns`（配对帧用 `left.sample_wall_ns`）。
MCAP 消息自带的 `log_time` 是到达刻（等于 `recv_wall_ns`），反映的是写入顺序，比采样刻晚一个链路延迟，不要用它对齐。
手套与 Tracker 的对齐方法、同步指标与时间相关的异常见《09-时间戳同步》。
Tracker 被遮挡、没有位姿时，该帧的 `pose` 为 `None`。

**零位**：录制文件里的 Tracker 位姿是基站坐标系下的绝对位姿（定义见《03-基站使用与配对》第 5.3 节）。
每次标定基站都会重建这个坐标系，所以只有同一次标定下录的绝对位姿可以直接比较。
第 2 节的录制脚本把启动时记下的零位写进每段文件的元数据 `revohuman.episode` → `reference`
（每只手一个 4×4 齐次矩阵 `tracker_ref`）；自己写录制程序时，要自己在 `rec.start(..., metadata=...)` 里带上它。
相对零位的增量按 `ΔR = R_refᵀ · R`、`Δp = R_refᵀ · (p − p_ref)` 计算，即在零位时刻 Tracker 自身坐标系中表达。

**同步与作废标记**：每段文件的元数据 `revohuman.sync_health` 记录这一段双手是否全程严格同步（`sync_strict`）
以及是否作废（`aborted` / `abort_reason`），第 4 节的读回脚本会打印它们。

## 4. 读回与导出

### 4.1 检查录制文件

把下面的脚本保存为 `~/revohuman_inspect.py`：

```python
"""读回 RevoHuman 录制文件：各话题条数、时长、速率、链路延迟，同步与作废标记，首帧示例。

用法：python3 ~/revohuman_inspect.py <文件.mcap>
"""
import statistics
import sys

from revohuman import recording
from revohuman.frames import PairedFrame


def sample_ns(frame):
    return frame.left.sample_wall_ns if isinstance(frame, PairedFrame) else frame.sample_wall_ns


def main() -> int:
    if len(sys.argv) != 2:
        print(__doc__, file=sys.stderr)
        return 2
    topics = {}
    with recording.open(sys.argv[1]) as reader:
        for msg in reader:
            t = topics.setdefault(msg.topic, {"n": 0, "stamps": [], "lag": [], "first": msg.frame})
            t["n"] += 1
            s = sample_ns(msg.frame)
            if s is not None:
                t["stamps"].append(s)
                t["lag"].append((msg.log_time_ns - s) / 1e6)
        meta = reader.metadata()

    print(f"{'话题':<16}{'条数':>8}{'时长(s)':>10}{'速率(Hz)':>10}{'链路延迟中位数(ms)':>20}")
    for name in sorted(topics):
        t = topics[name]
        span = (max(t["stamps"]) - min(t["stamps"])) / 1e9 if len(t["stamps"]) > 1 else 0.0
        rate = (len(t["stamps"]) - 1) / span if span > 0 else 0.0
        lag = statistics.median(t["lag"]) if t["lag"] else float("nan")
        print(f"{name:<16}{t['n']:>8}{span:>10.2f}{rate:>10.1f}{lag:>20.2f}")

    health = meta.get("revohuman.sync_health", {})
    episode = meta.get("revohuman.episode", {})
    print("双手全程严格同步：", "是" if health.get("sync_strict") else "否",
          "  本段作废：", "是（" + str(health.get("abort_reason")) + "）" if health.get("aborted") else "否")
    print("零位：", (episode.get("reference") or {}).get("calibration_id", "无"))

    if "/paired" in topics:
        f = topics["/paired"]["first"]
        print("/paired 首帧：skew_ns =", f.skew_ns,
              " 左手前 3 个关节角(度) =", [round(v, 2) for v in f.left.joints_deg[:3]])
    for hand in ("left", "right"):
        name = f"/tracker/{hand}"
        if name in topics and topics[name]["first"].pose is not None:
            p = topics[name]["first"].pose
            print(f"{name} 首帧：位置(米) =", [round(v, 4) for v in p.position],
                  " 姿态(w,x,y,z) =", [round(v, 4) for v in p.rotation])
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```bash

```

### 4.2 导出为 CSV

把下面的脚本保存为 `~/revohuman_export_csv.py`：

```python
"""把 RevoHuman 录制文件导出为 CSV：双手关节角一个文件，每只 Tracker 一个文件。

用法：python3 ~/revohuman_export_csv.py <文件.mcap>
输出（与录制文件同目录）：<名>_joints.csv、<名>_tracker_left.csv、<名>_tracker_right.csv
"""
import csv
import pathlib
import sys

from revohuman import recording
from revohuman.joint_map import joint_names


def main() -> int:
    if len(sys.argv) != 2:
        print(__doc__, file=sys.stderr)
        return 2
    src = pathlib.Path(sys.argv[1]).expanduser()
    stem = src.with_suffix("")
    names = joint_names()
    outputs = {}

    def writer(key, header):
        if key not in outputs:
            fp = open(f"{stem}_{key}.csv", "w", newline="", encoding="utf-8")
            w = csv.writer(fp)
            w.writerow(header)
            outputs[key] = [fp, w, 0]
        return outputs[key]

    with recording.open(src) as reader:
        for msg in reader:
            f = msg.frame
            if msg.topic == "/paired":
                out = writer("joints", ["sample_wall_ns"]
                             + [f"left_{n}_deg" for n in names] + [f"right_{n}_deg" for n in names])
                out[1].writerow([f.left.sample_wall_ns, *f.left.joints_deg, *f.right.joints_deg])
            elif msg.topic.startswith("/tracker/"):
                hand = msg.topic.rsplit("/", 1)[1]
                out = writer(f"tracker_{hand}",
                             ["sample_wall_ns", "x_m", "y_m", "z_m", "qw", "qx", "qy", "qz"])
                pose = [*f.pose.position, *f.pose.rotation] if f.pose is not None else [""] * 7
                out[1].writerow([f.sample_wall_ns, *pose])
            else:
                continue
            out[2] += 1
    for key, (fp, _, rows) in outputs.items():
        fp.close()
        print(f"{stem}_{key}.csv：{rows} 行")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

导出第一段：

```bash
python3 ~/revohuman_export_csv.py ~/revohuman_data/demo/episode_001.mcap
head -n 2 ~/revohuman_data/demo/episode_001_tracker_left.csv
```

得到三个文件：

| 文件 | 列 |
|---|---|
| `episode_001_joints.csv` | `sample_wall_ns`，左手 21 个关节角，右手 21 个关节角（度），每行一个配对帧 |
| `episode_001_tracker_left.csv` | `sample_wall_ns`、`x_m`、`y_m`、`z_m`、`qw`、`qx`、`qy`、`qz` |
| `episode_001_tracker_right.csv` | 同上 |

关节角列名形如 `left_<关节名>_deg`。Tracker 被遮挡没有位姿的行，位姿列为空。

## 5. 作废的段

录制中出现下列情况时，SDK 会把当前这一段标为作废：「已保存」一行后面跟一行「本段已作废」，
文件照常写完，但元数据里 `aborted` 为真，这段数据不要使用。

| 情况 | 原因 | 之后 |
|---|---|---|
| 手套时间戳质量下降（USB 链路不稳、主机时钟跳变） | 这段时间的采样刻不可信 | 自动恢复后可以继续录 |
| 基站被遮挡、可用基站不够，持续 3 秒 | 位姿不可靠 | 条件消失后可以继续录 |
| 基站被碰歪（倾斜达到 2°）、被检测到移动，或位姿与标定记录不符 | 坐标系已经变了 | 本次运行不能再录，重新标定基站（《03-基站使用与配对》）后重新运行 |
| 所有 Tracker 停止出数据 10 秒 | Tracker 断开 | 检查连接后重新运行 |

基站被平移或水平转动时检测不到，这一段不会被标为作废；动过基站就重新标定（见《03-基站使用与配对》第 8 节）。

本次运行不能再录时，下一段开始就会报错退出，报错信息带错误码，含义见《07-日志与错误码》。

## 6. 数据量

P1 双手加两只 Tracker 的录制文件约 **10 MB/分钟**（实测 10 秒一段 1.65 MB），即约 0.6 GB/小时，
按这个数估算磁盘空间。录制文件使用 lz4 压缩。

导出的 CSV 大小与原录制文件相近（实测三个 CSV 合计 1.44 MB）。

## 7. 实时广播 revohuman-live

`revohuman-live` 打开整套手套与 Tracker，把关节角与 Tracker 位姿实时广播给本机的订阅方
（三维可视化的实时模式，见《05-仿真与可视化》）。它**不录制数据**；
它运行期间手套和 Tracker 被它占用，录制与 ROS 2 节点都要等它退出（`Ctrl-C`）后再运行。

| 参数 | 默认 | 说明 |
|---|---|---|
| `--product {auto,P1,PTV1}` | `auto` | 型号。`auto` 自动识别；写 `P1` 时与在位硬件不符会报错退出 |
| `--hands {both,left,right}` | `both` | 打开哪只手 |
| `--no-tracker` | 关 | 不打开 Tracker，只广播手套数据 |
| `--tracker-gate {flag,error}` | `flag` | 基站检查没通过时：`flag` 照常广播位姿，并在状态里标出哪一项没过；`error` 不广播位姿 |
| `--tracker-phi-pack SERIAL=毫秒` | 无 | 一只 Tracker 的打包延迟标定值，`SERIAL` 是 Tracker 的序列号（形如 `LHR-XXXXXXXX`）；每只 Tracker 写一条，可重复。给了的 Tracker，位姿的采样时间戳扣掉这段延迟；只在跨模态做毫秒级绝对对齐时需要，不给时表现为一个固定偏置（见《RevoHuman SDK 参考手册》第 6.1 节「绝对相位」） |
| `--sync {best-effort,on,off}` | `best-effort` | 双手硬件同步：`best-effort` 同步失败也照常广播；`on` 同步失败即报错；`off` 不做硬件同步 |
| `--socket SOCKET` | 自动 | 广播用的本机 socket 路径，一般不用改 |
| `-v` | 关 | 打印调试日志 |

注意 `--tracker-gate` 的默认值是 `flag`，便于边看画面边排查基站问题；
第 2 节的录制脚本使用 `error`（SDK 默认），基站检查不通过时直接拒绝启动，不会录下坐标系不可信的数据。

只用左手、不开 Tracker 检查手套数据：

```bash
revohuman-live --hands left --no-tracker
```

`revohuman-live` 会一直运行，用 `Ctrl-C` 结束。日常使用时直接运行 `revohuman-live`。

## 8. 用手套按键开始/结束录制

第 2 节的脚本按固定秒数录。也可以改用手套上的按键控制：按一下开始录一段，再按一下结束，不必回到键盘前。

按键默认不开启，打开整套时需要显式传 `glove_kwargs={"button": True}`。开启后按键状态随手套数据一起上报，
不改变采样率。按键需要支持按键的手套固件；固件不支持时，显式开启按键会打一条 `N2406`
（见《07-日志与错误码》第 3 节），数据流照常。本节脚本遇到这种情况会提示后以退出码 `3` 退出。

把下面的脚本保存为 `~/revohuman_button_record.py`：

```python
"""RevoHuman P1 按键录制：打开双手手套与 Tracker，按一下手套上的按键开始录一段，再按一下结束。

用法：python3 ~/revohuman_button_record.py <输出目录> [right|left]
例：  python3 ~/revohuman_button_record.py ~/revohuman_data/button right
第二个参数选用哪只手套上的按键，默认 right。按 Ctrl-C 退出（正在录的那段会先保存）。
"""
import logging
import pathlib
import queue
import sys
import time

from revohuman import ButtonMode, RevoHumanError, format_error, open_kit

EXIT_BUTTON_UNSUPPORTED = 3


def countdown(text: str, seconds: int) -> None:
    for n in range(seconds, 0, -1):
        print(f"{text}：{n}", flush=True)
        time.sleep(1)


def wait_supported(button, timeout_s: float = 10.0):
    """按键是否可用要等手套开始出数据后才知道：True 支持，False 不支持，None 等不到数据。"""
    deadline = time.monotonic() + timeout_s
    while button.supported is None and time.monotonic() < deadline:
        time.sleep(0.1)
    return button.supported


def report(i: int, s: dict) -> int:
    print(f"[{i}] 已保存：{s['frames']} 帧，{s['bytes'] / 1e6:.2f} MB，"
          f"{s['duration_sec']:.1f} 秒；各话题 {s['per_channel']}", flush=True)
    if s["aborted"]:
        print(f"[{i}] 本段已作废：{s['abort_reason']}", flush=True)
        return 1
    return 0


def main() -> int:
    if len(sys.argv) not in (2, 3) or sys.argv[2:] not in ([], ["left"], ["right"]):
        print(__doc__, file=sys.stderr)
        return 2
    out_dir = pathlib.Path(sys.argv[1]).expanduser()
    hand = sys.argv[2] if len(sys.argv) == 3 else "right"
    out_dir.mkdir(parents=True, exist_ok=True)
    logging.basicConfig(level=logging.INFO,
                        format="%(asctime)s %(levelname)s %(name)s: %(message)s")

    countdown("双手摆到零位并保持不动", 5)
    try:
        kit = open_kit("P1", glove_kwargs={"button": True})
    except RevoHumanError as exc:
        print(format_error(exc), file=sys.stderr)
        return 1

    aborted = 0
    with kit:
        ref = kit.tracker.reference
        print(f"零位已记下（{ref.calibration_id[:8]}），可以开始动作", flush=True)
        geometry = kit.geometry()
        if not geometry["ok"]:
            print(f"基站几何不达标：{geometry['errors']}；按《03-基站使用与配对》重新标定后再录",
                  file=sys.stderr)
            return 1
        button = kit.glove(hand).button
        supported = wait_supported(button)
        if supported is None:
            print(f"{hand} 手套 10 秒内没有数据，按《02-硬件连接》检查连接", file=sys.stderr)
            return 1
        if not supported:
            print(f"{hand} 手套的固件不支持在采集期间上报按键，请改用第 2 节的定时录制",
                  file=sys.stderr)
            return EXIT_BUTTON_UNSUPPORTED
        rec = kit.recorder()
        presses = button.subscribe()
        handle, episode = None, 0
        print(f"按一下 {hand} 手套上的按键开始录制，再按一下结束；Ctrl-C 退出", flush=True)
        try:
            while True:
                try:
                    ev = presses.recv(timeout=1.0)
                except queue.Empty:
                    continue
                if ev.missed_presses:
                    print(f"（有 {ev.missed_presses} 次按压没有单独收到，以手套当前状态为准）", flush=True)
                if ev.mode is ButtonMode.START and handle is None:
                    episode += 1
                    path = out_dir / f"episode_{episode:03d}.mcap"
                    handle = rec.start(str(path), metadata={
                        "product": "P1", "episode": episode, "reference": ref.to_payload()})
                    print(f"[{episode}] 录制中：{path}（再按一下按键结束）", flush=True)
                elif ev.mode is ButtonMode.END and handle is not None:
                    aborted += report(episode, handle.stop())
                    handle = None
                elif ev.mode is ButtonMode.END:
                    print("手套报「结束」，当前没在录；再按一下开始", flush=True)
        except KeyboardInterrupt:
            print("已按 Ctrl-C 停止录制", flush=True)
        except RevoHumanError as exc:
            print(format_error(exc), file=sys.stderr)
            aborted += 1
        finally:
            presses.close()
            if handle is not None:
                aborted += report(episode, handle.stop())
            rec.close()
    return 1 if aborted else 0


if __name__ == "__main__":
    sys.exit(main())
```

两个参数依次是输出目录、用哪只手套上的按键（`right` 或 `left`，默认 `right`）。
零位与基站检查和第 2 节相同；每按一次「开始」就新录一段，依次存成 `episode_001.mcap`、`episode_002.mcap`……
按 `Ctrl-C` 会先保存正在录的那一段，然后退出。

用右手手套的按键控制：

```bash
python3 ~/revohuman_button_record.py ~/revohuman_data/button right
```

按键的规则：

- 手套自己记着「开始」「结束」两个状态，每按一次切换一次，长按不会连续切换，上电时是「结束」。
- 脚本启动后看到的第一个状态只作基准，不算一次按压。启动前按过按键的话，第一下可能报「结束」，
  脚本会提示「当前没在录；再按一下开始」。
- 按得太快、中间有按压没有单独收到时，脚本打印「有 n 次按压没有单独收到」，并以手套当前的状态为准：
  当前是「开始」就开始录（已在录则继续录），是「结束」就结束这一段。
- 只认参数指定的那只手套上的按键，另一只手套上的按键不起作用。
  两只手套都会开启按键，所以另一只的固件不支持时也会打一条 `N2406`，不影响录制。
- 段的起止以脚本收到按键的时刻为准，比按下略晚，适合用来划分段，不适合做精确对时。按键本身不写进录制文件。
- USB 断开重连、或数据流因自检等操作重开之后，期间的按压不会补报，重开后的第一个状态重新作为基准。

程序退出码：`0` 正常退出；`1` 打开失败、基站几何不达标、有段作废或运行中出错；`2` 参数不对；
`3` 手套固件不支持在采集期间上报按键。

## 9. 在自己的程序里读实时数据

第 2、8 节的脚本只负责录制。要在自己的程序里边采边用数据（实时控制、显示、在线分析），就直接读 SDK 的订阅。
本节说明哪些调用会阻塞、三种读法怎么选，以及读不过来、断线、关闭时会发生什么。
各接口的完整说明见《RevoHuman SDK 参考手册》第 6.3 节。

### 9.1 哪些调用会阻塞

SDK 的接口都是普通的同步函数，采集在 SDK 自己的后台线程里进行，不需要你的程序去轮询设备。
读数据有两类接口：

- **订阅**（`subscribe()`）：一帧不漏地按顺序拿数据。支持阻塞读、回调和 asyncio 三种读法。
- **最新值**：不阻塞，立即返回当前最新的那一份。

| 调用 | 是否阻塞 | 说明 |
|---|---|---|
| `open_kit()`、`GloveManager().connect()` / `connect_pair()` | 阻塞 | 打开设备并做启动检查。`open_kit()` 要等基站与 Tracker 就绪，约 15 秒。返回时不等第一帧数据 |
| `kit.close()`、离开 `with` | 阻塞 | 停止采集，等后台线程退出 |
| `sub.recv(timeout=t)` | 最多阻塞 `t` 秒 | 有帧立即返回；`t` 秒内没有帧抛 `queue.Empty`。`timeout=0` 不等待，不给 `timeout` 会一直等 |
| `await sub.recv_async(timeout=t)` | 不阻塞事件循环 | 只挂起当前协程，不占线程池；超时同样抛 `queue.Empty` |
| `kit.tracker.latest(hand)` / `kit.tracker.delta(hand)` | 不阻塞 | 立即返回该手 Tracker 的最新一帧与它的年龄（秒）/ 相对零位的增量 |
| `glove.button.read()` | 不阻塞 | 立即返回最新的按键状态（第 8 节） |
| `rec.start(...)` / `handle.stop()` | 阻塞 | `stop()` 等文件完整写完才返回 |
| `stats()` / `status()` | 不阻塞 | 当前统计的快照 |

`open_kit()`、`connect()`、`close()` 没有 asyncio 版本。在 asyncio 程序里用 `await asyncio.to_thread(...)` 调用它们，
免得卡住事件循环（见 9.3 的例子）。

### 9.2 订阅是一个有界队列

- 每调用一次 `subscribe()` 得到一个独立的订阅，每一帧都会投进每一个订阅。
  需要在几处用同一路数据时，各自 `subscribe()` 一次，不要让几个线程读同一个订阅：一帧只会交给其中一个读者。
- 订阅是一个有界队列。手套与双手配对帧默认最多存 64 帧（200 Hz 下约 0.3 秒），可以用 `subscribe(queue_size=...)` 调大。
- 读得比数据来得慢时，队列满了**丢掉最旧的帧**，采集本身不受影响。丢了多少看 `sub.dropped_count`。
- 手套没有「最新一帧」接口。只要最新值时，把队列里攒下的帧一次读空，留最后一帧：

  ```python
  import queue

  def newest(sub, timeout=1.0):
      """等到至少一帧，再把队列里积压的读空，返回最新的那一帧。"""
      f = sub.recv(timeout=timeout)
      while True:
          try:
              f = sub.recv(timeout=0)
          except queue.Empty:
              return f
  ```

- **时间戳门关着时没有帧**。默认的订阅只派发时间戳合格的帧，所以在两种情况下手套一帧都不派，读的一方只会看到 `queue.Empty`：
  - 刚打开手套时的短暂预热；
  - 时间戳质量下降期间（日志 `N2102`，见《09-时间戳同步》）。

  是否处在这种状态看 `glove.capture_ok`，为 `False` 时 `glove.capture_cause` 给出原因。
  只做实时显示、不需要精确时间戳时，可以用 `glove.subscribe(gated=False)`：这期间照常出帧，但这些帧的 `gate_open` 为 `False`，
  `sample_wall_ns` 不保证精度。录制器不接受这种订阅。
- **断线重连期间同样没有帧**。重连后自动恢复，恢复后帧的 `generation` 加 1。

### 9.3 三种读法

**阻塞读**：在自己的线程或主循环里用 `recv(timeout=...)`。例子里每拿到一对手套帧，顺带取一次 Tracker 的最新位姿：

```python
import queue
from revohuman import open_kit

with open_kit("P1") as kit:
    sub = kit.synchronizer().subscribe()          # 双手配对帧，200 Hz
    for _ in range(2000):                         # 约 10 秒
        try:
            pf = sub.recv(timeout=1.0)            # 最多等 1 秒
        except queue.Empty:
            gl, gr = kit.glove("left"), kit.glove("right")
            print("1 秒内没有数据，时间戳门：", gl.capture_ok, gr.capture_ok)
            continue
        tf, age_s = kit.tracker.latest("right")   # 不阻塞
        if tf is not None and age_s < 0.1:
            print(pf.left.sample_wall_ns, pf.right.joints_deg[:3], tf.pose.position)
    print("丢帧：", sub.dropped_count)
```

**回调**：`subscribe(callback=函数)`，SDK 为这个订阅单独开一个后台线程，按顺序一帧一帧调用它：

```python
def on_pair(pf):
    ...                                           # 在该订阅自己的线程里执行

sub = kit.synchronizer().subscribe(callback=on_pair)
```

- 回调慢时同样按上一小节的规则丢最旧的帧，不会拖慢采集。
- 回调里抛出的异常不会中断采集，也**不会打印**，只把最近一次记在 `sub.last_error`。回调里自己用 `try` 处理并记日志。
- 回调里不要关闭这个订阅本身；回调形式的订阅也不要再调 `recv()`。

**asyncio**：`await sub.recv_async(timeout=...)` 或 `async for`。打开、关闭这类阻塞调用放进 `asyncio.to_thread`：

```python
import asyncio
from revohuman import open_kit

async def main():
    kit = await asyncio.to_thread(open_kit, "P1")
    try:
        sub = kit.synchronizer().subscribe()
        async for pf in sub:                      # 订阅关闭时循环结束
            ...                                   # 不要在这里做长时间的同步计算
    finally:
        await asyncio.to_thread(kit.close)

asyncio.run(main())
```

### 9.4 关闭与出错

- `kit.close()`（或离开 `with`）会关闭全部订阅。之后在订阅上 `recv()` / `recv_async()` 抛 `Disconnected`（错误码 `1101`），`async for` 自然结束。
- 同步的 `for f in sub:` 如果关闭时正在等待，会抛 `Disconnected`；要么用 `try` 包住，要么像 9.3 那样用 `recv(timeout=...)` 循环，并检查 `sub.closed`。
- 拿到 `Disconnected` 之后不要再对同一个订阅调用 `recv()`：关闭的通知只送达一次，再调会一直等下去（带 `timeout` 时抛 `queue.Empty`）。
  判断订阅是否已关闭用 `sub.closed`。
- 订阅也可能因为不可恢复的故障而关闭，这时 `recv()` 抛该故障对应的异常，`async for` 也不会吞掉它。
  例如基站被移动时 Tracker 订阅抛 `WorldFrameChanged`（`1902`）。统一捕获 `RevoHumanError` 即可，含义见《07-日志与错误码》第 4 节。
- **`kit.tracker.latest()` / `delta()` 不抛异常。** Tracker 被遮挡、出故障或已关闭时，它们仍返回最后一次收到的位姿，只是年龄 `age_s` 越来越大。
  所以要用 `age_s` 判断位姿是否新鲜（Tracker 约 250 Hz，正常时 `age_s` 远小于 0.1 秒），
  用 `kit.fatal`（或 `kit.raise_if_fatal()`）判断是否出了不可恢复的故障。
  这类故障发生后只有 Tracker 停止，手套数据照常流动；整套要重开进程才能恢复，见《03-基站使用与配对》第 7 节。
- 读数据的程序和录制脚本、`revohuman-live`、ROS 2 节点一样独占手套与 Tracker，不能与它们同时运行。

## 10. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 报错码 `1102`，提示串口被占用 | 另一个程序正打开着手套（`revohuman-live`、可视化实时模式、ROS 2 节点或另一个录制脚本），先关掉它 |
| 报错码 `1900` | Tracker 驱动已被另一个程序占用，同上 |
| 报错码 `1905`，Tracker 未就绪 | 启动检查没通过。报错里列出了原因和处理办法，多数是基站没开机、被遮挡或需要重新标定，见《03-基站使用与配对》 |
| 报错码 `1804`，型号不符 | 在位的不是 P1 手套，或某只手的 Tracker 没接上。先跑 `python3 -m revohuman product identify` 看识别结果 |
| 报「left 手的手套不在位」（或 right） | 这只手套没接好，按《02-硬件连接》第 3 节检查；本章的录制脚本需要两只手套都在位 |
| 报错码 `1600`，录制门关着 | 手套时间基准还没建立好，刚上电时等几秒再录；反复出现检查 USB 线缆与 HUB |
| 「基站几何不达标」 | 基站被移动过或标定已失效，按《03-基站使用与配对》重新标定 |
| 按键录制脚本以退出码 `3` 退出，日志有 `N2406` | 这只手套的固件不支持在采集期间上报按键，改用第 2 节的定时录制 |
| 按了按键没有开始录 | 按的不是参数指定的那只手套；或启动前按过按键，第一下报了「结束」，再按一下即可 |
| 「本段已作废」 | 见第 5 节 |

全部错误码与日志说明见《07-日志与错误码》。
